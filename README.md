# LAST LIGHT

*Fire. Shadow. Time. One survives.*

A third-person 1v1 arena duel made in **Godot 4.7.2**. Fight a bot or a friend on a split screen: pistols at range, knives up close, punches to shove, a **Fire** power that burns, a **Shadow** power that blinds, and a red zone that shrinks with **Time**.

## Play
Download `LastLight.exe` from the **Releases** page and double-click it. No install needed (Windows 10/11, DirectX 12 GPU). If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.

## Open the project
1. Install [Godot 4.7.2](https://godotengine.org/download) (standard version).
2. Clone this repository and open `project.godot` in Godot.
3. Press **F5**.
